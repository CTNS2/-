# Cystinosis Mutation Database

Static site (no build step). Open `index.html` to view it locally.

- `index.html` – page structure and the per-variant pages
- `css/styles.css`, `css/mobile.css` – styles
- `js/app.js` – navigation, tables, search, translations
- `js/gene-viewer.js` – CTNS gene / coding-sequence viewer (selection, Tm, primers)
- `js/lollipop.js` – CTNS protein lollipop + AlphaMissense panel

Deployed on Netlify from the `main` branch (publish directory `.`).
